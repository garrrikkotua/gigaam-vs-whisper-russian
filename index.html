GigaAM vs Whisper on Russian speech

A compact, inspectable archive of two model outputs on the same 200 short utterances from the Golos Crowd test split. The package includes references, hypotheses, checksums, one unmodified audio example, and a verifier that needs only Python 3.

The verifier scores the stored normalized strings. It does not download models or rerun inference. The archived reports identify mutable model names rather than immutable weight hashes, so bit-for-bit inference reproduction is not guaranteed.

What the sample can and cannot answer

Both archived reports use the same deterministic first 200 rows from a local Golos Crowd test manifest, the same word normalization, and corpus WER: total substitutions, insertions, and deletions divided by total reference words.

  • The short Crowd phrases do not represent interviews, meetings, lectures, every accent, or every acoustic condition.
  • Training-data overlap was not investigated.
  • WER does not measure punctuation, speaker labels, formatting, or manual editing time.
  • The archived runtime observations were not a controlled speed benchmark.
  • Only the first audio clip is redistributed; the manifest retains SHA-256 hashes for all 200 clips.

Кратко по-русски

Это открытый архив сравнения GigaAM v3 RNNT и Whisper large-v3 на одинаковых 200 коротких записях Golos Crowd. Скрипт verify.py заново считает WER по сохранённым эталонам и гипотезам. Он проверяет арифметику, но не запускает модели. Подробная методика и ограничения перечислены выше и в файле METHODS.
